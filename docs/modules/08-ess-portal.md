# الموديول 8: ESS Portal (بوابة الخدمة الذاتية للموظف)

## الهدف

كل تعاملات الموظف مع HR من موبايله — بعربية مبسطة تناسب العمالة الزرقاء، وبلا حاجة لإيميل شركة.

## مبادئ التصميم

1. **موبايل أولاً:** PWA (تطبيق ويب تقدمي) — بلا متجر تطبيقات في الـ MVP، قابل للتغليف كتطبيق Native في Phase 3
2. **دخول بدون إيميل:** رقم الموبايل + OTP عبر SMS/WhatsApp (Supabase Phone Auth) — الإيميل اختياري للـ White Collar
3. **عربية مبسطة:** جمل قصيرة، أيقونات كبيرة، أزرار واضحة — تُختبر مع مستخدمين من العمالة الفعلية
4. **يعمل بشبكة ضعيفة:** Offline-first لتسجيل الحضور، مزامنة عند توفر الشبكة
5. **نطاق صارم:** الموظف يرى نفسه فقط (RLS: `employee_id = jwt.employee_id`)

## الوظائف

| الوظيفة | التفاصيل |
|---|---|
| بياناتي | عرض الملف + تعديل (عنوان/موبايل/طوارئ/صورة) بمراجعة Personnel |
| مستنداتي | رفع المستندات بالكاميرا مباشرة (الـ AI يصنف ويطابق الـ Checklist) + تنبيهات ما يوشك على الانتهاء |
| الحضور | Check-in/out بزر واحد (GPS) + سجل شهري |
| الإجازات | رصيدي + طلب إجازة + متابعة الحالة |
| الراتب | قسيمة الراتب الشهرية (PDF عربي) + البدلات والـ KPI — **بعد مصادقة إضافية (PIN)** |
| السلف | طلب سلفة + متابعة الأقساط |
| الـ Onboarding | للموظف الجديد: قائمة المطلوب منه خطوة بخطوة |
| الاستقالة | تقديم استقالة إلكترونية (يفتح حالة Offboarding) + الـ Handover والـ Clearance الخاصة به |
| الإشعارات | كل ما يخصه: اعتمادات، مواعيد، انتهاء مستندات |
| توقيع الإقرارات | إقرار استلام الـ Handbook، السياسات (Phase 3: eSignature كامل) |

## واجهة المدير داخل ESS

المدير المباشر يحصل على تبويب إضافي: اعتماد إجازات وأوفرتايم فريقه، صندوق اعتماداته، حضور الفريق اليوم — حتى لا يحتاج فتح النظام المكتبي للقرارات اليومية.

## الشاشات

الرئيسية (بطاقات: حضوري اليوم، رصيد إجازاتي، إشعاراتي) · ملفي · مستنداتي · حضوري · إجازاتي · راتبي · طلباتي · (للمدير: فريقي).

## الأتمتة والذكاء الاصطناعي

- **HR Chatbot عربي (Phase 3 — AI Copilot):** "رصيدي كام؟" / "امتى هينزل المرتب؟" — إجابات من بياناته هو فقط
- تذكيرات WhatsApp بالمطلوب منه (مستند ناقص، توقيع، فحص طبي)
- إشعار فوري عند: اعتماد إجازته، نزول راتبه، اقتراب انتهاء مستند
