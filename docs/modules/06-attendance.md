# الموديول 6: Attendance (الحضور)

> **خارج نطاق الدليل** — الدليل لا يغطي الحضور. صُمم استكمالاً لاحتياجات مواقع المقاولات وبما يتسق مع دورة الـ Payroll (الاستقطاعات والأوفرتايم تدخل مرحلة Deductions & Adjustments أيام 20–23).

## الهدف

تسجيل حضور موثوق لقوى عاملة موزعة بين مكاتب ومواقع إنشاء، بأقل احتكاك ممكن للعمالة الزرقاء، وتغذية الـ Payroll آلياً.

## التحديات الخاصة بالمقاولات وكيف نحلها

| التحدي | الحل |
|---|---|
| مواقع متعددة بلا أجهزة بصمة | **GPS Check-in من موبايل الموظف مع Geofence** حول الموقع (إحداثيات `work_locations`) |
| عمالة زرقاء بلا هواتف ذكية أحياناً | **تسجيل بالإنابة من مشرف الموقع** (Site Supervisor): كشف حضور يومي رقمي يعلّم منه فريقه — مع توثيق هوية المشرف |
| ورديات ومناوبات ليلية | تعريف `shifts` مرنة لكل موقع (صباحية/مسائية/24 ساعة بالتبادل) |
| الانتقال بين مواقع في نفس اليوم | تسجيلات متعددة بموقعين مختلفين مقبولة وتُنسب للمشروعين |
| التلاعب في الـ GPS | تحقق Geofence + عشوائية طلب صورة سيلفي + مراجعة الشذوذ بالـ AI |

## النموذج

- `shifts`: الاسم، الموقع، البداية/النهاية، أيام العمل، سماحية التأخير، معامل الأوفرتايم
- `attendance_records` (مقسم شهرياً): الموظف، التاريخ، دخول/خروج، الطريقة (gps / site_supervisor / manual)، الموقع المتحقق، دقائق التأخير، دقائق الأوفرتايم، الحالة (حاضر/غائب/إجازة/مأمورية)، سبب الاستثناء
- تكامل اختياري Phase 2: أجهزة بصمة في المكاتب الرئيسية (استيراد ملفات/API)

## القواعد

1. الغياب غير المبرر يولّد استثناءً يراجعه المدير المباشر → إن اعتُمد كخصم يتدفق لـ Payroll Stage 5 كتسوية **بمستند واعتماد** (Policies 4، 7)
2. الأوفرتايم يتطلب اعتماد المدير المباشر قبل دخوله الحساب
3. الإجازات المعتمدة (موديول Leave) تُعلَّم تلقائياً في الحضور — لا تضارب
4. قفل سجل الشهر مع قفل دورة الـ Payroll

## الشاشات

| الشاشة | لمن |
|---|---|
| Check-in/out (زر واحد كبير، عربي مبسط، يعمل Offline ويُزامن) | ESS — موبايل |
| كشف حضور الموقع اليومي (تعليم جماعي) | مشرف الموقع |
| لوحة حضور الفريق + اعتماد الاستثناءات والأوفرتايم | المدير المباشر |
| لوحة الحضور العامة (بالموقع/المشروع/القسم) + التقارير | HR / Operations |
| ملخص الشهر التمهيدي للـ Payroll | Payroll |

## الأتمتة والذكاء الاصطناعي

- إغلاق يومي تلقائي وتعليم الغياب لمن لا تسجيل له ولا إجازة
- تنبيه فوري للمدير عند غياب أحد فريقه
- **كشف الأنماط بالـ AI:** تأخير متكرر، تسجيلات متطابقة مشبوهة من مشرف، شذوذ GPS
- تقرير ساعات العمل بالمشروع (يدعم تحميل التكلفة والفوترة)
