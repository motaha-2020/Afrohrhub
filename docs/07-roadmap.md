# 07 — خارطة الطريق وترتيب التنفيذ

## المراحل المنتجية

### MVP — الإطلاق الأول
Core HR · Recruitment · Onboarding · Attendance · Leave · Payroll & Allowances & KPI · Offboarding · Approval Engine · ESS · Notifications

**معيار اكتمال الـ MVP:** شركة مقاولات واحدة (Pilot) تدير دورة كاملة حقيقية: طلب توظيف → تعيين → تفعيل → راتب مدفوع → خروج موظف — بدون الرجوع لـ Excel.

### Phase 2
Assets (سجل عهدة كامل بدورة حياة) · Training & HSE Certs (مصفوفة تدريب وتجديد شهادات) · Probation & Contracts (فترات اختبار وتجديدات بتنبيهات) · Performance (دورات تقييم) · Disciplinary (لائحة جزاءات مرتبطة بالـ Payroll)

### Phase 3
ATS Portal عام (صفحة وظائف لكل Tenant) · Manpower Planning (تخطيط القوى بالمشروع) · Advanced Analytics · eSignature معتمد · Org Chart تفاعلي · AI Copilot كامل (Chatbot عربي على بيانات الـ Tenant)

## ترتيب جلسات التنفيذ المقترح (بعد اعتماد هذه الوثائق)

| الجلسة | النطاق | المخرج القابل للاختبار |
|---|---|---|
| **1. التأسيس** | Scaffold المشروع (Next.js + Supabase + i18n/RTL) · Migrations النواة (tenants, users, الهيكل التنظيمي) · Auth (إيميل + موبايل OTP) · RLS · الأدوار | تسجيل دخول بدورين مختلفين لـ Tenant تجريبي |
| **2. Core HR** | جداول الموظفين والمستندات والـ Timeline · Status Engine · Directory + Profile 360° · إعدادات الهيكل | إنشاء موظف يدوياً بمستنداته وحالاته |
| **3. المحركات** | Approval Engine · SLA Engine (تعريفات مزروعة من الدليل) · Notifications (In-App + Email) | طلب يمر بسلسلة اعتماد بعدّاد SLA وإشعارات |
| **4. Recruitment** | المراحل 1–8 · Pipeline · Talent Pool · العروض وصفحة القبول | دورة توظيف كاملة حتى الـ Handover |
| **5. Onboarding** | المراحل 1–9 · المهام · بوابة التفعيل · توليد الـ Hiring Email والعقود | مرشح مقبول يصبح موظفاً Active |
| **6. Payroll** | الدورة الشهرية 1–9 · التسويات والسلف · حساب الضرائب والتأمينات · اعتماد Finance | دورة راتب شهرية كاملة بأرقام صحيحة |
| **7. Allowances + KPI + تقارير التكلفة** | الدورتان + التقارير بالمشروع | بدلات وKPI مدفوعة وموزعة على المشاريع |
| **8. Attendance + Leave** | الحضور (GPS + كشف المشرف) · الإجازات والأرصدة · التدفق للـ Payroll | حضور وإجازات تنعكس في الراتب |
| **9. Offboarding** | المراحل 1–6 · Clearance · التسوية النهائية (برصيد الإجازات) | خروج موظف كامل حتى الأرشفة |
| **10. ESS + WhatsApp** | بوابة الموظف PWA · قنوات WhatsApp/SMS · القوالب | موظف Blue Collar يسجل حضوره ويرى قسيمته من موبايله |
| **11. AI Layer** | OCR · Classifier · CV Parsing · Matching · البحث الدلالي | رفع بطاقة → حقول مملوءة؛ رفع CV → بروفايل مرتب |
| **12. صقل وإطلاق Pilot** | Import/Migration من Excel · SLA Dashboard · تدقيق أمني (RLS) · أداء | استيراد بيانات شركة حقيقية وتشغيل موازٍ لشهر |

> الترتيب يحترم الاعتمادية: لا Onboarding بدون Core HR والمحركات، ولا Payroll بدون تفعيل، ولا تسوية نهائية بدون أرصدة إجازات. الجلسات 6–8 قابلة للتوازي جزئياً إن توفر أكثر من مسار عمل.

## مخاطر مفتوحة (تُحسم مع الإدارة قبل الجلسة المعنية)

1. **تصحيح SLA الفرز (P1):** اعتماد "5 أيام عمل" رسمياً (قبل الجلسة 3)
2. **WhatsApp Business API:** يتطلب حساب Meta Business موثق وقوالب معتمدة — يبدأ إجراؤه مبكراً لطول دورة الاعتماد (قبل الجلسة 10)
3. **جداول ضرائب المرتبات والتأمينات:** تتغير سنوياً بقرارات — تُبنى كجداول قابلة للتحديث وتُراجع مع محاسب الشركة (قبل الجلسة 6)
4. **مزود SMS المصري:** اختيار المزود والتعاقد (قبل الجلسة 10)
5. **تقويم Payroll:** الدليل يحدد الأيام 18/19/23/25/28/10 — التأكد أنها واحدة لكل الـ Tenants أم قابلة للتهيئة (الافتراض الحالي: قابلة للتهيئة بقيم الدليل افتراضياً)
