# 06 — خريطة الشاشات والـ Navigation

## البنية العامة

- **تطبيق مكتبي (Back-office):** `app.afrohrhub.com/{tenant}` — لأدوار HR والإدارات
- **بوابة ESS:** نفس التطبيق بواجهة موبايل أولاً — للموظفين والمديرين (قراراتهم اليومية)
- **صفحات عامة بلا دخول:** قبول/رفض عرض العمل (Token)، رفع مستندات الموظف الجديد (Token)
- **لوحة Super Admin:** منفصلة — إدارة الـ Tenants والاشتراكات

كل شاشة تحمل مرجعها في وثيقة موديولها؛ هذه الخريطة للملاحة والأولوية فقط.

## الـ Navigation الرئيسي (Back-office) حسب الدور

| القسم في القائمة | الشاشات | يظهر لـ |
|---|---|---|
| **لوحة المعلومات** | KPIs عامة، عدادات SLA، مهامي، اعتماداتي | الجميع (محتوى حسب الدور) |
| **الموظفون** | Directory · Profile 360° · Import/Migration | HR, Personnel, Admin (+قراءة للأدوار) |
| **التوظيف** | طلبات التوظيف · Pipeline Board · Talent Pool · المقابلات · مقارنة المرشحين · العروض · تقارير | TA, HR Manager, المدير الطالب (نطاقه) |
| **الـ Onboarding** | Tracker · بطاقة الحالة · مهام قسمي · بوابة التفعيل | Personnel, HR, IT, HSE, Ops |
| **الـ Offboarding** | Tracker · بطاقة الحالة · مصفوفة الـ Clearance · Exit Interview · التسوية النهائية | Personnel, HR, IT, Ops, Finance |
| **الرواتب** | لوحة الدورة · السجل · التسويات والسلف · بدلات المشاريع · KPI · اعتماد وصرف · تقارير التكلفة بالمشروع | Payroll, Finance, PMO, PMs (نطاقهم) |
| **الحضور والإجازات** | لوحة الحضور · كشف الموقع · اعتمادات الفريق · لوحة الإجازات والأرصدة | HR, Ops, المديرون |
| **الاعتمادات** | صندوق اعتماداتي · مهيئ الـ Workflows | الجميع / Admin |
| **الإعدادات** | الهيكل التنظيمي · المشاريع والمواقع · أنواع المستندات · أنواع الإجازات · قوالب الإشعارات · قيم SLA · المستخدمون والأدوار | Company Admin, HR Manager |
| **التدقيق** | Audit Log · تقارير الالتزام | Company Admin, HR Manager |

## شاشات ESS (موبايل)

الرئيسية → ملفي · مستنداتي · حضوري (Check-in) · إجازاتي · راتبي (بـ PIN) · طلباتي · إشعاراتي · (للمدير: فريقي واعتماداتي) · تقديم استقالة.
